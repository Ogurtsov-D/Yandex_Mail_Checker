# Политика конфиденциальности

*Действует с 1 ноября 2026 г. для расширения «Счётчик писем для Яндекс Почты» (ранее — Yandex Mail Checker) версии 1.5.0 и новее.*

«Счётчик писем для Яндекс Почты» — расширение для браузера с открытым исходным кодом. Оно не собирает данные пользователей и не передаёт их ни автору, ни третьим лицам.

## К чему расширение обращается

- **Только к `mail.yandex.ru`.** Расширение получает счётчики почты (`https://mail.yandex.ru/api/v2/bar/counters`: число непрочитанных и число новых писем) и, когда пришли новые письма, страницу «Входящих» (`https://mail.yandex.ru/lite/inbox`). Запросы идут с cookie, которые браузер уже хранит для Яндекса. Расширение не видит ваш пароль и не хранит cookie.
- **Обновления в Firefox.** Если расширение установлено из файла `.xpi` со страницы релизов, сам Firefox периодически проверяет на `github.com`, не вышла ли новая версия, — так же, как проверяет обновления для дополнений из каталога Mozilla. Расширение при этом ничего не передаёт.
- **К вкладкам `mail.yandex.ru`.** Расширение видит адрес и заголовок только этих вкладок: чтобы переключаться на открытую почту и обновлять счётчик после чтения писем. Адреса и содержимое других вкладок ему недоступны.

## Что хранится и где

Все данные хранятся **только в вашем браузере** (`storage.local` и `storage.session`):

| Данные | Зачем |
|--------|-------|
| Число непрочитанных и новых писем, время и результат последней проверки | Показывать бейдж и подсказку, замечать новые письма |
| Номера (ID) до 100 последних непрочитанных писем | Не уведомлять об одном письме дважды |
| Настройки: интервал проверки, уведомления вкл./выкл. | Помнить ваш выбор |
| Номер письма из последнего уведомления (до закрытия браузера) | Открыть это письмо по клику |

Отправитель и тема писем используются только для показа уведомления и не сохраняются.

## Что расширение не делает

- Не передаёт данные на какие-либо серверы, включая `mail.yandex.ru`: оттуда оно только получает счётчики почты и страницу «Входящих».
- Не использует аналитику, трекеры и рекламу.
- Не читает содержимое писем и не выполняет действий в почте (не отмечает прочитанным, не удаляет, не отправляет).

## Как удалить данные

Удалите расширение — браузер сотрёт всё, что оно хранило.
