![Лицензия](https://img.shields.io/badge/license-GPLv3-blue.svg)
![Chrome](https://img.shields.io/badge/chrome-%3E%3D120-green)

**Расширение для Chrome и других Chromium-браузеров, которое показывает количество непрочитанных писем в Яндекс.Почте прямо на панели инструментов.**

![Счётчик на иконке, меню и уведомления](docs/screenshot.png)

<sub>Макет интерфейса: имена и темы писем вымышлены, внешний вид меню и уведомлений зависит от браузера и ОС.</sub>

## Возможности

| Функция | Описание |
|---------|----------|
| 🔔 **Счётчик на иконке** | Количество непрочитанных писем во «Входящих» |
| 📬 **Уведомления** | Системные уведомления о новых письмах с отправителем и темой |
| ⏱️ **Настраиваемый интервал** | Автопроверка каждые 1 / 5 / 15 / 30 минут (выбор в меню) |
| 🔄 **Ручная проверка** | ПКМ по иконке → «Проверить сейчас» |
| 🖱️ **Быстрый переход** | Клик по иконке открывает Яндекс.Почту в новой вкладке |
| ⚠️ **Понятные ошибки** | Различает «не авторизован», «нет сети», «ошибка сервера», «не удалось прочитать страницу» |
| 🔁 **Автоповтор при ошибках** | 2 быстрых повтора через 30 секунд, затем штатный интервал |
| 💾 **Сохранение состояния** | Помнит результат и настройки после перезапуска браузера |

## Установка

### Вариант 1: Chrome Web Store

*Скоро*

### Вариант 2: Ручная установка

```bash
git clone https://github.com/Ogurtsov-D/Yandex_Mail_Checker.git
```

Или скачайте ZIP: **Code → Download ZIP** на странице репозитория и распакуйте.

**Далее:**

1. Откройте `chrome://extensions/`
2. Включите «Режим разработчика» (Developer mode)
3. Нажмите «Загрузить распакованное расширение» (Load unpacked)
4. Выберите папку `Yandex_Mail_Checker`
5. Убедитесь, что вы вошли в Яндекс.Почту в этом же браузере

### Совместимость

Работает в Chrome 120+ и браузерах на его основе: Яндекс Браузер, Microsoft Edge, Brave, Opera, Vivaldi.
Уведомления работают в Windows, macOS и Linux.

## Использование

### Основные действия

| Действие | Результат |
|----------|-----------|
| **Левый клик** по иконке | Открывает Яндекс.Почту в новой вкладке |
| **Правый клик** по иконке | Контекстное меню с настройками |

### Контекстное меню

| Пункт | Описание |
|-------|----------|
| **Проверить сейчас** | Принудительная проверка почты |
| **Интервал проверки** | Подменю: 1 / 5 / 15 / 30 минут (текущий отмечен ✓) |
| **🔔 Уведомления** | Включить или выключить системные уведомления |

### Уведомления

Уведомление показывается, когда во «Входящих» появляется письмо, о котором расширение ещё не сообщало:

- **Одно письмо** — отправитель и тема
- **Несколько писем** — количество и до 3 писем (отправитель + тема)
- **Клик по уведомлению** — открывает Яндекс.Почту

При первом запуске расширение запоминает уже имеющиеся непрочитанные письма и не уведомляет о них.
Уведомления можно отключить через контекстное меню.

### Индикация на бейдже

| Бейдж | Значение |
|-------|----------|
| **Число (1–99+)** | Количество непрочитанных писем |
| **Пусто** | Нет новых писем |
| **?** | Требуется вход в Яндекс.Почту |
| **!** | Нет сети, ошибка сервера или страницу почты не удалось прочитать (подробности в подсказке) |
| **↻** | Идёт ручная проверка |

### Подсказка (tooltip)

При наведении на иконку отображается `Яндекс.Почта (3 минуты назад)` — время последней проверки.
При ошибке — её описание, например `Яндекс.Почта — Нет подключения (только что)`.

## Как это работает

Расширение использует **lite-версию** Яндекс.Почты (`https://mail.yandex.ru/lite/inbox`), потому что она:

- быстрее загружается и потребляет меньше трафика;
- отдаёт простой HTML, который легко разобрать;
- не требует API-ключей — используется ваша обычная сессия в браузере.

**Процесс работы:**

1. Service worker запрашивает lite-страницу «Входящих» с заданным интервалом
2. Извлекает количество непрочитанных, а также ID, отправителя и тему непрочитанных писем
3. Сравнивает ID писем с уже известными и уведомляет только о новых
4. Обновляет бейдж и подсказку
5. Сохраняет результат в `chrome.storage.local`

**Обработка ошибок:**

| Ситуация | Бейдж | Поведение |
|----------|-------|-----------|
| Не авторизован (редирект на passport.yandex.ru) | `?` | Ждёт следующую штатную проверку |
| Нет сети | `!` | 2 повтора через 30 секунд, затем штатный интервал |
| Яндекс не ответил за 20 секунд | `!` | Так же, как при отсутствии сети |
| Ошибка сервера (5xx) | `!` | Так же, как при отсутствии сети |
| Страница не распознана (капча, изменилась вёрстка) | `!` | Ждёт следующую штатную проверку |

## Ограничения

- Учитываются только письма во **«Входящих»**; другие папки и метки не проверяются.
- Поддерживается только **`mail.yandex.ru`**; `mail.yandex.com`, `.by`, `.kz`, `.com.tr` пока не поддерживаются.
- Проверяется только **основной аккаунт**, в который выполнен вход в браузере.
- Отправитель и тема в уведомлениях берутся с первой страницы списка писем.
- Расширение зависит от вёрстки lite-версии. Если Яндекс изменит или закроет её, расширение покажет `!` с подсказкой «Не удалось прочитать страницу почты» до выхода обновления.

## Решение проблем

**Бейдж `?`, хотя я вошёл в почту.**
Убедитесь, что вход выполнен именно на `mail.yandex.ru` в том же профиле браузера. Откройте https://mail.yandex.ru/lite/inbox — если там просят войти, войдите и нажмите «Проверить сейчас».

**Бейдж `!` и подсказка «Не удалось прочитать страницу почты».**
Откройте https://mail.yandex.ru/lite/inbox: если Яндекс показывает капчу, пройдите её. Если страница открывается нормально, а ошибка остаётся — вероятно, изменилась вёрстка; создайте [Issue](https://github.com/Ogurtsov-D/Yandex_Mail_Checker/issues).

**Не приходят уведомления.**
Проверьте, что уведомления включены в контекстном меню расширения, в настройках браузера (`chrome://settings/content/notifications`) и в системе (Windows: «Параметры → Уведомления», macOS: «Системные настройки → Уведомления» для вашего браузера). Также проверьте режим «Не беспокоить».

**Как посмотреть логи.**
`chrome://extensions/` → карточка расширения → ссылка **service worker** → вкладка Console. Приложите эти логи к Issue, удалив из них личные данные.

## Конфиденциальность

- Расширение обращается **только** к `mail.yandex.ru`, используя вашу сессию в браузере.
- Количество писем, ID последних писем и настройки хранятся **локально** в `chrome.storage.local`.
- Отправитель и тема писем используются только для показа уведомления и нигде не сохраняются.
- Никакие данные не передаются автору или третьим лицам; аналитики и трекеров нет.

## Технические детали

### Технологии

- **Manifest V3** — современная архитектура расширений Chrome
- **Service Worker** — фоновая работа без постоянного процесса
- **Chrome Alarms API** — периодические проверки
- **Chrome Notifications API** — системные уведомления
- **Chrome Storage API** — сохранение состояния и настроек
- **Context Menus API** — контекстное меню

### Разрешения

| Разрешение | Зачем |
|------------|-------|
| `storage` | Сохранение настроек и состояния |
| `alarms` | Периодическая проверка почты |
| `contextMenus` | Контекстное меню на иконке |
| `notifications` | Системные уведомления о новых письмах |
| `https://mail.yandex.ru/*` | Доступ к lite-версии почты |

### Структура проекта

```
├── manifest.json     # описание расширения и разрешения
├── background.js     # вся логика: проверка, разбор HTML, бейдж, уведомления, меню
├── icon16/32/48/128.png
├── docs/
│   ├── screenshot.png  # картинка для README
│   └── mockup.html     # исходник картинки (макет интерфейса)
├── LICENSE
└── README.md
```

### Разработка

1. Внесите изменения в код
2. На `chrome://extensions/` нажмите ↻ (перезагрузить) на карточке расширения
3. Откройте консоль service worker (см. «Как посмотреть логи») и нажмите «Проверить сейчас»

Если меняются тексты меню, бейджа или уведомлений, обновите `docs/mockup.html` и пересоздайте `docs/screenshot.png` — например, откройте макет в Chrome и сделайте снимок страницы через DevTools (Ctrl+Shift+P → «Capture full size screenshot»).

### 1.2

## Дисклеймер

Данное расширение **не является официальным продуктом Яндекса** и **не связано с компанией Яндекс**. Это независимый open-source проект.

Расширение только читает lite-страницу «Входящих» от имени уже вошедшего пользователя: не обходит капчи и авторизацию, не выполняет действий в почте, не изменяет страницы Яндекса и не показывает рекламу. Минимальный интервал проверки — 1 минута.

Если представители Яндекса считают, что расширение нарушает их правила, свяжитесь с автором через [Issues](https://github.com/Ogurtsov-D/Yandex_Mail_Checker/issues) для обсуждения доработки или удаления репозитория.
