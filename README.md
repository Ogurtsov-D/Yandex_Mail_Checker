**Расширение для Chrome, которое показывает количество непрочитанных писем в Яндекс.Почте прямо на панели инструментов.**

## Возможности

| Функция | Описание |
|---------|----------|
| 🔔 **Счетчик на иконке** | Отображает количество непрочитанных писем прямо на иконке расширения |
| ⏱️ **Автоматическая проверка** | Проверяет почту каждые 5 минут (настраиваемо) |
| 🔄 **Ручная проверка** | ПКМ по иконке → "Проверить сейчас" |
| 🖱️ **Быстрый переход** | Клик по иконке — открывает Яндекс.Почту в новой вкладке |
| 📊 **Информационное окно** | Всплывающее окно с точным количеством писем |
| ⚠️ **Индикация ошибок** | Показывает ! при проблемах с подключением |
| 💾 **Сохранение состояния** | Помнит последний результат даже после перезапуска браузера |

## Установка

### Вариант 1: Chrome Web Store 
*Скоро*

### Вариант 2: Ручная установка 

`git clone https://github.com/yourusername/yandex-mail-checker`

`cd yandex-mail-checker`

**Далее:**
1. Откройте Chrome и перейдите на chrome://extensions/
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку с проектом

## Использование

### Основные действия

| Действие | Результат |
|----------|-----------|
| **Левый клик** по иконке | Открывает Яндекс.Почту в новой вкладке |
| **Правый клик** по иконке → "Проверить сейчас" | Принудительная проверка почты |
| **Клик на расширение** → всплывающее окно | Показывает точное количество писем |

### Цветовая индикация

- 🔴 **Красное число** — есть непрочитанные письма
- ⚫ **Нет числа** — нет новых писем
- ⚠️ **Красный !** — ошибка подключения
- 🔄 **Красный ↻** — идет проверка

## Как это работает

Расширение использует **мобильную версию** Яндекс.Почты (lite-версию), потому что она:

✅ Быстрее загружается (меньше JavaScript)
✅ Потребляет меньше трафика
✅ Легче парсится (чистый HTML)
✅ Не требует дополнительных API ключей

**Процесс работы:**

1. Фоновый сервис каждые 5 минут запрашивает https://mail.yandex.ru/lite/inbox
2. Парсит HTML в поисках числа непрочитанных писем
3. Обновляет бейдж на иконке
4. Сохраняет результат в chrome.storage.local

## Технические детали

### Технологии

- **Manifest V3** — современная архитектура расширений Chrome
- **Service Worker** — фоновые процессы без постоянной памяти
- **Chrome Alarms API** — эффективные периодические проверки
- **Chrome Storage API** — сохранение состояния
- **Context Menus API** — контекстное меню для ручной проверки

### Настройка

В файле `background.js` можно изменить интервал проверки:

`const CHECK_INTERVAL = 5; // минут. Можно поставить 0.5 для 30 секунд`
