# Безопасность

Нашли уязвимость — **не создавайте публичный Issue**, отправьте закрытое сообщение: вкладка **Security** → **[Report a vulnerability](https://github.com/Ogurtsov-D/Yandex_Mail_Checker/security/advisories/new)**. Его увидит только автор.

Опишите, что не так, как воспроизвести (версия расширения, браузер, шаги) и, если есть, как исправить. Не прикладывайте настоящие письма, cookie и другие личные данные.

Проект некоммерческий, сроки ответа не гарантированы; исправления выходят только для последней версии.

*Found a vulnerability? Please report it privately via **Security → Report a vulnerability**, in English or Russian.*
