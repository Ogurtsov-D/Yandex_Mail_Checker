# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/).

## [1.5.0] — 2026-11-01

Большое обновление. Расширение получило новое название — «Счётчик писем для Яндекс Почты» (Checker for Yandex Mail) — и новую иконку. Счётчик теперь берётся у самого Яндекса и совпадает с числом в почте. Появились поддержка нескольких аккаунтов, Яндекс 360 и других доменов Яндекса, тихие часы, страница настроек и интерфейс на 19 языках. Для Firefox расширение публикуется в каталоге дополнений Firefox.

### Добавлено

- **Несколько аккаунтов.** На значке — сумма по всем аккаунтам, в подсказке — строка на каждый. Аккаунты подписаны основным адресом почты (на странице настроек им можно дать свои имена и не учитывать лишние). Правый клик по иконке показывает аккаунты с числом писем и открывает выбранный; уведомление подписано аккаунтом и открывает его
- **Другие адреса почты:** `mail.yandex.com`, `mail.yandex.by`, `mail.yandex.kz`, `mail.yandex.com.tr` и Яндекс 360 (`mail.360.yandex.ru`, в том числе почта на своём домене). Адрес выбирается на странице настроек, доступ к нему браузер спрашивает только при выборе
- **Страница настроек:** адрес почты, аккаунты, тихие часы, пауза при простое, горячая клавиша, вид значка. В Chrome и Edge открывается во вкладке
- **Тихие часы:** в заданное время (по умолчанию 23:00–08:00) уведомления не показываются
- **Звук уведомлений** отключается в меню (Chrome, Edge и другие браузеры на основе Chromium)
- **Режим значка «Только новые»:** на значке — письма, пришедшие после последнего захода в почту
- **Пауза, пока вы не за компьютером:** при простое или заблокированном экране плановые проверки не идут, при возвращении почта проверяется сразу (новое разрешение `idle`)
- **Горячая клавиша** Alt+Shift+Y открывает почту
- **Вид значка на выбор:** классический, минималистичный, синий, зелёный, фиолетовый
- **Интерфейс на 19 языках:** русский, английский (с 24-часовым временем в британском варианте), украинский, белорусский, казахский, узбекский, азербайджанский, армянский, грузинский, турецкий, немецкий, французский, румынский, латышский, эстонский, финский, иврит, китайский (упрощённый и традиционный). Язык выбирается по языку браузера
- Политика конфиденциальности на английском (`PRIVACY.en.md`)

### Изменено

- **Счётчик совпадает со счётчиком Яндекс Почты:** непрочитанные письма во всех папках, кроме «Спама». Число расширение получает от Яндекса, а не подсчитывает по странице «Входящих»
- **Уведомления** приходят, когда Яндекс сообщает о новых письмах, в том числе в других папках. В уведомлении — число новых писем, клик открывает почту; когда вы откроете почту, уведомление исчезает само. Отправителя и темы в таком уведомлении нет: загрузка страницы почты сбрасывала бы счётчик новых писем во всех ваших браузерах (они есть только на запасном пути, когда счётчики Яндекса недоступны)
- **Подсказка** показывает, сколько из непрочитанных писем новых, а ошибку — на текущем языке браузера
- **Меню иконки:** подменю «На значке» и «Уведомления» (показывать уведомления, звук, тихие часы)
- **Новое название и иконка:** жёлтый конверт с оранжевым клапаном, на странице расширений и в магазинах — с кружком-счётчиком
- **Firefox:** расширение публикуется в каталоге дополнений Firefox и обновляется через него; установленная из файла версия 1.4 перейдёт на версию из каталога сама. Минимальная версия Firefox — 142
- Плановые проверки идут с небольшим случайным разбросом времени

### Исправлено

- Больше тысячи непрочитанных писем: счётчик больше не показывает «1» вместо «1 234»
- Запасной подсчёт по упрощённой версии почты (когда счётчики Яндекса недоступны): число определяется и по списку папок, отправитель и тема читаются надёжнее, клик по уведомлению об одном письме открывает это письмо по адресу нового формата (для цепочки писем и нескольких писем — почту)

### Для разработчиков

- Тексты интерфейса — в `_locales/*/messages.json`, формы числа — по `Intl.PluralRules`; тест проверяет полноту всех переводов
- Иконки рисует скрипт `scripts/render-icons.mjs` из геометрических фигур — сторонних изображений в расширении нет
- Сквозные проверки в настоящих Chromium и Firefox: `npm run e2e`, `npm run e2e:firefox`
- Релиз отправляет Firefox-версию в каталог Mozilla (`scripts/amo-metadata.json`); при сбое релиз, созданный вручную, становится черновиком, повторный запуск его доопубликовывает
- Тексты и картинки для магазинов — `docs/store/`, картинки пересоздаёт `scripts/store-images.mjs`
- Английская версия README — `README.en.md`
- Действия GitHub Actions обновлены до v7, за новыми версиями следит Dependabot

## [1.4.0] — 2026-10-31

### Добавлено

- Почта на `mail.yandex.com`, `mail.yandex.by`, `mail.yandex.kz`, `mail.yandex.com.tr` и в Яндекс 360 (`mail.360.yandex.ru`, в том числе на своём домене): адрес выбирается на странице настроек, доступ к нему браузер спрашивает только при выборе
- Несколько аккаунтов: на значке — сумма, в подсказке — строка на каждый аккаунт; аккаунты подписаны основным адресом почты; правый клик показывает аккаунты с числом писем и открывает выбранный; уведомления подписаны аккаунтом и открывают его; на странице настроек аккаунтам можно дать свои имена и не учитывать лишние
- Интерфейс на украинском, белорусском, казахском, узбекском, азербайджанском, армянском, грузинском, турецком, немецком, французском, румынском, латышском, эстонском, финском, иврите и китайском (упрощённом и традиционном); в британском английском — 24-часовое время
- Звук уведомлений отключается в меню (Chrome и браузеры на его основе)
- Тихие часы: ночью уведомления не показываются; время задаётся на странице настроек
- Режим значка «Только новые»: на значке — письма, пришедшие после последнего захода в почту
- Пауза, пока вы не за компьютером: при простое или заблокированном экране плановые проверки не идут, при возвращении почта проверяется сразу (новое разрешение `idle`)
- Горячая клавиша Alt+Shift+Y открывает почту
- Страница настроек
- Плановые проверки идут с небольшим случайным разбросом времени

### Изменено

- Firefox: расширение публикуется в каталоге дополнений Firefox и обновляется через него; установленная из файла версия 1.4 перейдёт на версию из каталога сама
- Политика конфиденциальности на английском (`PRIVACY.en.md`)

- Подсказка на иконке показывает время проверки («Проверено в 14:32») и количество непрочитанных писем
- При ошибке подсказка показывает и ошибку, и последний успешный результат
- Пункты меню «Интервал проверки» и «Уведомления о новых письмах» используют стандартные галочки браузера

### Для разработчиков

- Код разделён на модули в `src/`, иконки перенесены в `icons/`
- Автотесты (`npm test`), линтер и проверка форматирования (`npm run lint`), сборка архивов (`npm run build`)
- GitHub Actions: проверка каждого изменения и автоматическая сборка релиза по тегу
- Отладочные логи включаются флагом `DEBUG` в `src/config.js`

- Новые письма определяются по ID: нет пропусков, когда одно письмо прочитано и одно пришло; нет уведомлений о старых письмах при установке
- Иконка 128×128 для Chrome Web Store
