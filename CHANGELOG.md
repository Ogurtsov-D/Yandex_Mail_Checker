# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/).

## [1.4.0] — 2026-10-31

### Изменено

- Подсказка на иконке показывает время проверки («Проверено в 14:32») и количество непрочитанных писем
- При ошибке подсказка показывает и ошибку, и последний успешный результат
- Пункты меню «Интервал проверки» и «Уведомления о новых письмах» используют стандартные галочки браузера

### Для разработчиков

- Код разделён на модули в `src/`, иконки перенесены в `icons/`
- Автотесты (`npm test`), линтер и проверка форматирования (`npm run lint`), сборка архивов (`npm run build`)
- GitHub Actions: проверка каждого изменения и автоматическая сборка релиза по тегу
- Отладочные логи включаются флагом `DEBUG` в `src/config.js`

## [1.3.0] — 2026-10-31

### Добавлено

- Клик по иконке переключает на уже открытую вкладку почты вместо открытия новой
- Клик по уведомлению об одном письме открывает это письмо
- Счётчик обновляется через несколько секунд после чтения почты во вкладке
- Поддержка Firefox 128+

## [1.2.0] — 2026-10-31

### Исправлено

- Таймаут запроса к Яндексу (20 секунд): зависший запрос больше не блокирует проверки
- Повторы при ошибке сети больше не зацикливаются
- Нераспознанная страница (капча, изменившаяся вёрстка) показывается как ошибка, а не как «0 писем»
- Счётчик не привязан к русскому языку интерфейса
- Кавычки, `&` и другие символы в уведомлениях отображаются правильно
- Новые письма определяются по ID: нет пропусков, когда одно письмо прочитано и одно пришло; нет уведомлений о старых письмах при установке
- Иконка 128×128 для Chrome Web Store

## [1.1.0] — 2026-02-14

### Добавлено

- Системные уведомления с отправителем и темой
- Настраиваемый интервал проверки
- Различение типов ошибок и автоповтор

## [1.0.0] — 2026-02-14

- Первый выпуск: счётчик непрочитанных писем на иконке
