# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/).

## [1.5.0] — 2026-11-01

### Добавлено

- Почта на `mail.yandex.com`, `mail.yandex.by`, `mail.yandex.kz`, `mail.yandex.com.tr` и в Яндекс 360 (`mail.360.yandex.ru`, в том числе на своём домене): адрес выбирается на странице настроек, доступ к нему браузер спрашивает только при выборе
- Несколько аккаунтов: на значке — сумма, в подсказке — строка на каждый аккаунт; правый клик показывает аккаунты с числом писем и открывает выбранный; уведомления подписаны аккаунтом и открывают его; на странице настроек аккаунтам можно дать имена и не учитывать лишние
- Интерфейс на украинском, белорусском, казахском, узбекском, азербайджанском, армянском, грузинском, турецком, немецком, французском, румынском, латышском, эстонском, финском, иврите и китайском (упрощённом и традиционном); в британском английском — 24-часовое время
- Звук уведомлений отключается в меню (Chrome и браузеры на его основе)
- Тихие часы: ночью уведомления не показываются; время задаётся на странице настроек
- Режим значка «Только новые»: на значке — письма, пришедшие после последнего захода в почту
- Пауза, пока вы не за компьютером: при простое или заблокированном экране плановые проверки не идут, при возвращении почта проверяется сразу (новое разрешение `idle`)
- Горячая клавиша Alt+Shift+Y открывает почту
- Страница настроек
- Плановые проверки идут с небольшим случайным разбросом времени

### Изменено

- Счётчик на иконке совпадает со счётчиком Яндекс Почты: непрочитанные письма во всех папках, кроме «Спама». Число расширение получает от Яндекса, а не подсчитывает по странице «Входящих»
- Уведомление приходит, когда Яндекс сообщает о новых письмах, — в том числе о письмах в других папках. Когда вы откроете почту, уведомление исчезает само
- Подсказка показывает, сколько из непрочитанных писем новых — пришедших после последнего захода в почту
- Меню иконки: подменю «На значке» (все непрочитанные или только новые) и «Уведомления» (показывать уведомления, звук, тихие часы)
- Минимальная версия Firefox — 142 (была 140): с неё Firefox поддерживает объявление о том, что расширение не собирает данные, на всех платформах
- Новое название: «Счётчик писем для Яндекс Почты» (по-английски — Checker for Yandex Mail)
- Новая иконка в цветах Яндекса: жёлтый конверт с красным клапаном
- Английский интерфейс: язык меню, подсказки и уведомлений выбирается по языку браузера
- Подсказка показывает ошибку на текущем языке браузера, даже если она случилась до смены языка

### Исправлено

- Клик по уведомлению открывает письмо по адресу нового формата `#/message/<номер>`; для цепочки писем открывается почта
- Больше тысячи непрочитанных писем: счётчик больше не показывает «1» вместо «1 234»
- Счётчик определяется и по списку папок, если в заголовке страницы числа нет
- Отправитель и тема письма в уведомлении читаются из разметки, которую подтверждают другие расширения для lite-версии; разбор не зависит от точной вложенности тегов

### Для разработчиков

- Тексты интерфейса — в `_locales/ru` и `_locales/en`, склонение через `Intl.PluralRules`
- Исходник иконки — `icons/icon.svg`, PNG собираются скриптом `scripts/render-icons.mjs`
- Английская версия README — `README.en.md`
- Сквозные проверки в настоящих Chromium и Firefox: `npm run e2e`, `npm run e2e:firefox`
- Релиз публикуется только с подписанным `.xpi` для Firefox; при сбое релиз, созданный вручную, становится черновиком, повторный запуск его доопубликовывает
- Обновлены действия GitHub Actions: `checkout`, `setup-node`, `upload-artifact` до v7; Dependabot следит за новыми версиями

## [1.3.0] — 2026-10-31

### Добавлено

- Клик по иконке переключает на уже открытую вкладку почты вместо открытия новой
- Клик по уведомлению об одном письме открывает это письмо
- Счётчик обновляется через несколько секунд после чтения почты во вкладке
- Поддержка Firefox 128+

## [1.2.0] — 2026-10-31

### Исправлено

- Таймаут запроса к Яндексу (20 секунд): зависший запрос больше не блокирует проверки
- Повторы при ошибке сети больше не зацикливаются
- Нераспознанная страница (капча, изменившаяся вёрстка) показывается как ошибка, а не как «0 писем»
- Счётчик не привязан к русскому языку интерфейса
- Кавычки, `&` и другие символы в уведомлениях отображаются правильно
- Новые письма определяются по ID: нет пропусков, когда одно письмо прочитано и одно пришло; нет уведомлений о старых письмах при установке
- Иконка 128×128 для Chrome Web Store
